A deterministic, long-only cbBTC bot for make.fun's simulated 24-hour race. It enters when the 8-bar trend turns positive, then exits on a three-bar reversal or a 2% close-mark loss trigger; fills occur at the next open and remain subject to fees and slippage.

## Run it

```sh
node main.ts
```
